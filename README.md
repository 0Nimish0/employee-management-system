# Employee Management System

A browser-based Employee Management System built with HTML, CSS, and JavaScript. The application provides an HR-style interface for managing employee information, departments, and employee-related operations.

## Features

* Employee dashboard
* Add new employees
* Edit employee information
* Delete employees
* Search employees
* Filter employee records
* Department management
* Employee portal
* Employee profile/details view
* Form validation
* Responsive user interface
* Dynamic DOM updates
* Multi-page navigation

## Employee Management

The system allows users to manage employee records through a simple interface.

Users can:

* Add employee details
* View employee information
* Edit existing employee records
* Delete employees
* Search for employees
* Filter employee records

## Departments

The departments section provides an organized view of employees based on their departments.

It demonstrates how employee information can be grouped and displayed for an HR-style workflow.

## Employee Portal

The employee portal provides a separate interface for viewing employee-related information and demonstrates how different pages and user flows can be structured within an employee management application.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/0Nimish0/employee-management-system.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using a local development server such as Live Server.

4. Explore the dashboard, employee management, departments, and employee portal.

## How It Works

The application uses JavaScript and DOM manipulation to dynamically manage employee information and update the interface.

Employee forms collect information, while JavaScript handles operations such as adding, editing, deleting, searching, and filtering employee records.

The JavaScript functionality is separated into different files for different areas of the application, keeping the project organized and easier to maintain.

## Purpose

This project was created to practice building a practical business application using JavaScript, DOM manipulation, forms, CRUD operations, event handling, and responsive web design.

It demonstrates how frontend technologies can be used to create an HR-style management interface.
